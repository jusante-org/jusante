# Segurança

O Jusante guarda dados de municípios e de moradores. Levamos segurança a sério.

## Como relatar uma vulnerabilidade

**Não abra uma issue pública.** Use o recurso de [relato privado de vulnerabilidades do GitHub](https://github.com/jusante-org/jusante/security/advisories/new).

Inclua, se possível:

- descrição do problema e do impacto;
- passos para reproduzir;
- versão ou commit afetado.

Responderemos em até 7 dias úteis e manteremos você informado até a correção.

## Versões com suporte

O projeto ainda não tem versões publicadas. Assim que houver, esta seção indicará quais recebem correções de segurança.
